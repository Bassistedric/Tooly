# Inspection template seed data

This folder contains normalized reference data extracted from the source control workbook.

Principles:
- templates are shared by equipment type/category, not duplicated per equipment;
- source periodicity text is retained only for traceability and is not an operational scheduling rule;
- scheduling remains on InspectionRequirement;
- published template versions are immutable historical references;
- completed controls store structured answers and can later be rendered as PDF on demand.
