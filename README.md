# Tooly

Tooly is a multi-entity equipment and tool management platform.

Initial design principles:
- modular backend and frontend architecture;
- FR / NL / EN / PL from the start;
- stable business identifiers;
- equipment, assignment, inspection and document history preserved;
- manual equipment number entry and progressive QR deployment;
- no company-specific business data hard-coded in the application.

Current phase: foundation and domain model setup.
